# 🧮 Python Calculator

Welcome to my Python Calculator Project!

This is a simple and user-friendly calculator application developed using **Python** and **Tkinter**. The project provides a graphical user interface (GUI) where users can perform basic mathematical calculations easily.

## 📌 About the Project

I created this project as part of my Python programming practice. The main goal of this project is to understand how Python can be used to create a simple desktop application with a graphical user interface.

The calculator has a clean and simple design with buttons for numbers, mathematical operators, and useful editing functions.

## ✨ Features

The calculator supports the following features:

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🔢 Decimal number calculations
- ⌫ Backspace
- 🔄 Plus / Minus (+/-)
- 🧹 Clear button
- 🟰 Equal button
- 🖥️ Simple graphical user interface

## 🛠️ Technologies Used

- **Python**
- **Tkinter**
